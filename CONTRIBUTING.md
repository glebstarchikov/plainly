# Contributing

Open pull requests against `main`. Keep each change to one feature or fix, and use a conventional commit message.

Local setup is in the README. Run `npm run lint` before you open a pull request. This repository has no automated test suite. GitHub Actions runs lint, the build, and the migrations against PostgreSQL 16.

Plainly is a fork of [Pages CMS](https://pagescms.org) (see [NOTICE](NOTICE)). Keep the MIT copyright notices in LICENSE when you redistribute it.
