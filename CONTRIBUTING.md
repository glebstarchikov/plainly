# Contributing

Open pull requests against `main`. Keep each change to one feature or fix, and use a conventional commit message.

Local setup is in the README. Run `npm run lint` before you open a pull request. This repository has no automated test suite. GitHub Actions runs `npm ci` and `npm run build`.

Plainly is a fork of [Pages CMS](https://pagescms.org). Keep the MIT copyright notices when you redistribute it.
